# Builder Skills

Agent skills distilled from the best builders' own advice, sourced and ready to use. Every rule links to the person's own post.

## Skills

- [nikita-x-skill](./nikita-x-skill/) — Nikita Bier's (X head of product) tips for growing on X, taken only from his own posts on @nikitabier: 12 rules, each linked to the original post, plus a pre-post checklist.
- [emil-agent-skills-ui](./emil-agent-skills-ui/) — Emil Kowalski (@emilkowalski) tips for using agent skills on design and UI work. Use when installing, sequencing, or writing UI/animation agent skills, combining design skills with other agent skills, running animation or mobile-native skill workflows, or packaging UI taste into a SKILL.md for coding agents.
- [emil-product-ux](./emil-product-ux/) — Emil Kowalski (@emilkowalski) product UX feel tips for agents. Use when fixing perceived speed, toast/ephemeral feedback, touch vs scroll friction, mobile-web papercuts, readable body type, text-wrap, composer affordances, in-page find in accordions, worst-case content stress tests, or validating why before hi-fi prototypes - complementary to emil-agent-skills-ui.
- [x-algo-latest](./x-algo-latest/) — Latest X algorithm updates: ranking weights, cold-start boost, AI-reply detection, how to apply them and refresh them.
- [defi-app-ui-ux](./defi-app-ui-ux/) — DeFi frontend UX: CTA hierarchy, positions, wallets, permissions, signing and transaction recovery.
